## 3. Caveats

- **Multi-Process In-Memory Repository**: Tests verify thread-safety and concurrency within Python's asyncio event loop and ThreadPoolExecutor. If the backend is deployed across multiple OS processes without a shared database (e.g., multi-worker Uvicorn), data synchronization across processes requires Redis or external persistence, which is outside the scope of the current single-process in-memory architecture.
- **Python `csv` Standard Library Quoting Limitation**: If a raw binary byte stream contains random ASCII quote (`"`) and newline (`\n`) characters, Python's built-in `_csv.reader` will raise `csv.Error`. While the API catches standard errors, hardening `csv_adapter.py` to intercept `csv.Error` explicitly in production code is recommended for defense-in-depth against malicious CSV payloads.
